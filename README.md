# 📚 Online Book Store

A Django-based Online Book Store web application that allows users to browse, search, filter, and purchase books through a simple and user-friendly interface.

The project also provides a Django Admin Panel for managing books, categories, users, orders, and newsletter subscribers. Gemini AI is integrated to provide AI-generated book summaries.

---

## 🎯 Project Objective

The main objective of this project is to develop a lightweight and user-friendly online bookstore where users can:

- Create an account and log in
- Browse available books
- Search and filter books
- View detailed book information
- Add books to cart
- Checkout and place orders
- View order history
- Subscribe to newsletters
- Get AI-generated book summaries
